# [ENG] Mechanical Keyboard Sounds Android

Mechanical keyboard sound system for SA-MP on Android. Plays realistic mechanical keyboard sounds based on game actions, with support for on-screen keyboard and mouse visualization. MonetLoader 3.8.0-os+.

## Features

- Mechanical keyboard sounds triggered by in-game actions
- Separate sound assignment for each action
- Custom sound pack support (MP3)
- On-screen keyboard visualization (4 styles)
- On-screen mouse visualization (2 styles)
- Gamepad support
- Fade-in effect on sounds
- PT/EN/ES translation
- Automatic library installer (downloads required libraries if missing)

## Commands

- `/stm` - Opens the mod menu
- `/keyboardpc` - Opens the mod menu

## Support

- MonetLoader 3.8.0-os+
- SA-MP 0.3.7
- Architectures arm64-v8a (64-bit) and armeabi-v7a (32-bit)

Requires MonetLoader 3.8.0-os+ and SA-MP 0.3.7

# [PT-BR] Mechanical Keyboard Sounds Android

Sistema de sons de teclado mecânico para SA-MP no Android. Reproduz sons realistas de teclado mecânico com base nas ações do jogo, com suporte a visualização de teclado e mouse na tela. MonetLoader 3.8.0-os+.

## Funcionalidades

- Sons de teclado mecânico acionados por ações do jogo
- Atribuição de som separada para cada ação
- Suporte a pacotes de som personalizados (MP3)
- Visualização de teclado na tela (4 estilos)
- Visualização de mouse na tela (2 estilos)
- Suporte a controle (gamepad)
- Efeito de fade in nos sons
- Tradução PT/EN/ES
- Instalador automático de bibliotecas (baixa as bibliotecas necessárias caso estejam faltando)

## Comandos

- `/stm` - Abre o menu do mod
- `/keyboardpc` - Abre o menu do mod

## Suporte

- MonetLoader 3.8.0-os+
- SA-MP 0.3.7
- Arquiteturas arm64-v8a (64-bit) e armeabi-v7a (32-bit)

Requer MonetLoader 3.8.0-os+ e SA-MP 0.3.7
